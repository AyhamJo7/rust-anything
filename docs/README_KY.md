## Тез баштоо

Муну код жазуучу агентиңизге коюңуз:

```text
Install Rust Anything with npm i -g rust-anything, then run rust-anything setup. Run rust-anything go -- <slow command of this app> and finish the port until rust-anything gate passes.
```

Же өзүңүз орнотуңуз:

```sh
cargo install rust-anything   # же: npm install -g rust-anything
rust-anything setup           # аны Claude Code, Codex, Cursor, Gemini CLI жана OpenCode'го кошот
rust-anything doctor          # түп нускаңызга керек иштетүү чөйрөлөрүн текшерет, ар бирине оңдоо жолун берет
```

> [!WARNING]
> Жазуу түп нусканын чыныгы кодун иштетет. Көчүрмө менен иштеңиз жана серверди тест маалымат базасына багыттаңыз.

> [!TIP]
> **Агенттерге:** орнотуу кадамдары, бардык буйруктар жана порттоо тартиби үчүн [rustanything.ai/llms.txt](https://rustanything.ai/llms.txt) окуңуз.

## Бул кантип иштейт

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/how-it-works/ky-dark.svg">
    <img src="assets/how-it-works/ky-light.svg" width="880" alt="analyze эмнени порттоону пландайт; rust-anything go көпүрө курат, жазат, портту агентиңизге берет жана gate аркылуу өткөрөт, жазылган ар бир учур дал келгенче кайталайт; андан кийин enable чакырууларды Rust'ка которот">
  </picture>
</p>

**Эмне даяр деп эсептелет.** Сиздин тесттериңиз эмес, жүрүм-турум. `record` түп нусканы генерацияланган жана берилген киргизүүлөр менен иштетип, ар бир чакыруу эмне кайтарарын, эмне ыргытарын жана эмне чыгарарын сактайт. Порт `gate` өткөндө даяр: жазылган ар бир учур дал келет, ошондой эле fmt, clippy, `cargo test`, `unsafe` текшерүүсү, stub текшерүүсү жана портко чапталган жазылган жоопторду текшерүү да өтөт. Өз тесттериңиз да иштейт.

**Тесттериңиз учурларга айланат.** `record --from-tests -- npx jest` (же `pytest`) түп нусканын өз тест топтомун иштетип, анын бирдикке жасаган ар бир чакыруусун жазат. `--pin-clock` эки тарапта тең саатты жана кокус сандарды бекитет, ошондуктан датага көз каранды код да дал келе алат.

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/how-it-works-app-dark.svg">
    <img src="assets/how-it-works-app-light.svg" width="880" alt="Бүтүн колдонмону порттоо: analyze аны пландайт, чечимдерди сиз кабыл аласыз, app record анын чыныгы жүрүм-турумун жазат, front door түп нусканын алдында Rust'ту иштетет, бирдиктер эч нерсе түп нускага кайтпай калганга чейин бир-бирден көчөт, андан кийин lift таза Rust колдонмосун калтырат">
  </picture>
</p>

**Бүтүн колдонмолор: CLI жана серверлер.** `app record` CLI'ды (чыгуу коду, stdout, stderr, жазылган файлдар) же `--http` менен сервердин ар бир суроого берген жоопторун жазат. `app front-door` `rust/app` түзөт: кирүү чекитин өзүнө алган жана азырынча порттолбогон баарын түп нускага берген Rust бинардык файлы. `app wire` бирдиктерди бир-бирден көчүрөт, fallback үлүшү нөлгө түшкөнчө `app replay` 100%да турушу керек, ал эми `app lift` таза Rust колдонмосун калтырат.

**Кыйыр таасирлер да эсептелет.** Webhook'ту же катты жөнөтүүнү унуткан порт ийгиликсиз болушу керек. `app record --effects http,smtp` (же `--effect-env WEBHOOK_URL=http-url`) колдонмону ар бир чыгуучу чакырууну жана катты жазган жергиликтүү алмаштыргычтарга багыттайт, ал эми `--db-dump "sqlite3 app.db .dump"` ар бир суроодон кийин маалымат базасын жазат; replay порттун да ошондой кыларын текшерет.

**Түп нуска өзгөрө береби?** `app drift` түп нусканы анын жазуусуна каршы кайра иштетип, эми башкача жооп бергендердин тизмесин чыгарат, ал эми [GitHub Action](install.md#in-ci) ар бир push'та `gate` иштетет.

**Чечимди сиз кабыл аласыз.** Порттун жүрүм-турумун оңдогондо, `rules --add "<rule>"` аны сактайт, жана кийинки ар бир агент промпту аны камтыйт. rust-anything жазган баары `<repo>/rust/` ичинде.

**Отчет же көчүрүү, өзүңүз тандайсыз.** `analyze` жана `profile` отчет гана берет: эмнени порттоо керектигинин иреттелген планы жана чыныгы жүктөмдө эмне эң көп убакыт аларын. Булар жөнөкөй буйруктар, ошондуктан отчет эч кандай токен коротпойт. `go` бир бирдикти көчүрөт: эң ысык функцияга көпүрө курат, аны жазат, портту агентиңизге берет, андан кийин курайт, салыштырат жана `gate` аркылуу өткөрөт, баары дал келгенде гана күйгүзөт (TS/JS, Python жана PowerShell; `disable` кайра өчүрөт).

**Бир иштетүү канча убакыт алат.** Бир `go` иштетүүсү бир бирдикти порттойт, эң көп `--rounds` агент айлампасы менен (демейки боюнча 3): бири порт үчүн, андан кийин ар бир ийгиликсиз diff же gate үчүн бирден. Бүтүн колдонмо ар бир бирдикке бир иштетүүдөн турат, ошондуктан каалаганынан кийин токтосоңуз болот.

**План үчүн арзан модель, порт үчүн күчтүү модель.** План үчүн модель керек эмес. Порт үчүн каалаган агент буйругун бериңиз: `rust-anything go --agent "claude --model <model>" -- <workload>`.

**Агенттер.** `rust-anything setup` аны Claude Code, Codex, Cursor, Gemini CLI жана OpenCode'го кошот. Каалаган башка MCP кардары `rust-anything mcp` иштете алат, ал эми skill `npx skills add erkamyaman/rust-anything` аркылуу өзүнчө да орнотулат ([орнотуу](install.md) бөлүмүн караңыз).

## Буйруктар

| Буйрук | Эмне кылат |
| --- | --- |
| `rust-anything go -- <workload>` | Профилдейт, эң ысык функцияга көпүрө курат, аны жазат, портту агентиңизге берет, gate аркылуу өткөрөт, күйгүзөт |
| `rust-anything analyze <repo>` | Иреттелген көчүрүү планы: бирдиктер, даярдык, тобокелдиктер, көз карандылыктар |
| `rust-anything profile <repo> -- <workload>` | Чыныгы жүктөмдө эмне эң ысык экени, эмнени порттоо же топтоо керек |
| `rust-anything bridge <repo> <unit>` | Бир бирдик үчүн байланыштары бар Rust crate, stub'тар `src/port.rs` ичинде |
| `rust-anything record <crate>` | Түп нуска эмне кайтарарын, эмне ыргытарын жана эмне чыгарарын жазат (`--inputs`, `--from-tests`, `--pin-clock`) |
| `rust-anything diff <crate>` | Жазылган ар бир учурду Rust модулуна каршы кайра иштетет |
| `rust-anything bench <crate>` | Жазылган учурларда түп нуска менен Rust убактысын өлчөйт, көпүрөнү кошо |
| `rust-anything fuzz <crate>` | Эки тарапка тең жаңы киргизүүлөр: жазуу камтыбаган нерселер |
| `rust-anything gate <crate>` | Даярдыктын аныктамасы |
| `rust-anything enable` / `disable <crate>` | Чакыруучуларды Rust'ка которот же кайра кайтарат |
| `rust-anything report <crate>` | `REPORT.md` жана pull request үчүн карта |
| `rust-anything app record` / `front-door` / `wire` / `replay` / `lift` / `drift` | Бүтүн CLI'ды же серверди порттойт |
| `rust-anything rules <repo> --add "<rule>"` | Сиз оңдогон жүрүм-турум, кийинки ар бир порт сактайт |
| `rust-anything map <repo>` | Ар бир бирдик, анын crate'и, учурлары жана акыркы diff |
| `rust-anything setup` / `doctor` / `mcp` | Агенттер үчүн орнотуу, иштетүү чөйрөлөрүн текшерүү, MCP сервери |
