## Тиз башлау

Моны код язучы агентыгызга куегыз:

```text
Install Rust Anything with npm i -g rust-anything, then run rust-anything setup. Run rust-anything go -- <slow command of this app> and finish the port until rust-anything gate passes.
```

Яки үзегез урнаштырыгыз:

```sh
cargo install rust-anything   # яки: npm install -g rust-anything
rust-anything setup           # аны Claude Code, Codex, Cursor, Gemini CLI һәм OpenCode'ка өсти
rust-anything doctor          # оригиналыгызга кирәк булган эшләү мохитләрен тикшерә, һәрберсе өчен төзәтү юлын күрсәтә
```

> [!WARNING]
> Язу оригиналның чын кодын эшләтә. Күчермә белән эшләгез һәм серверны тест мәгълүмат базасына юнәлтегез.
> `record --sandbox` һәм `app record --sandbox` аны челтәрсез, репозиторийны укыр өчен генә хәлдә һәм CPU белән хәтер чикләүләре белән эшләтә (Linux'та bubblewrap, macOS'та sandbox-exec; `doctor` аның барлыгын тикшерә).

> [!TIP]
> **Агентларга:** урнаштыру адымнары, барлык боерыклар һәм портлау тәртибе өчен [rustanything.ai/llms.txt](https://rustanything.ai/llms.txt) укыгыз.

## Бу ничек эшли

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/how-it-works/tt-dark.svg">
    <img src="assets/how-it-works/tt-light.svg" width="880" alt="analyze нәрсәне портларга кирәклекне планлаштыра; rust-anything go күпер кора, яза, портны агентыгызга тапшыра һәм gate аша үткәрә, язылган һәр очрак туры килгәнче кабатлый; аннары enable чакыруларны Rust'ка күчерә">
  </picture>
</p>

**Нәрсә әзер дип санала.** Тестларыгыз түгел, программаның үз-үзен тотышы. `record` оригиналны ясалган һәм бирелгән кертү мәгълүматлары белән эшләтә һәм һәр чакыру нәрсә кайтарганын, нәрсә ыргытканын һәм нәрсә чыгарганын саклый. Порт `gate` үткәч әзер: язылган һәр очрак туры килә, шулай ук fmt, clippy, `cargo test`, `unsafe` тикшерүе, stub тикшерүе һәм портка куелган язылган җавапларны тикшерү дә үтә. Үз тестларыгыз да эшли.

**Тестларыгыз очракларга әйләнә.** `record --from-tests -- npx jest` (яки `pytest`) оригиналның үз тест җыелмасын эшләтә һәм аның берәмлеккә ясаган һәр чакыруын яза. `--pin-clock` ике якта да сәгатьне һәм очраклы саннарны беркетә, шуңа күрә датага бәйле код та туры килә ала.

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/how-it-works-app-dark.svg">
    <img src="assets/how-it-works-app-light.svg" width="880" alt="Бөтен кушымтаны портлау: analyze аны планлаштыра, карарны сез кабул итәсез, app record аның чын тотышын яза, front door оригинал алдында Rust'ны эшләтә, берәмлекләр бернәрсә дә оригиналга кайтмаганчы берәм-берәм күчә, аннары lift саф Rust кушымтасын калдыра">
  </picture>
</p>

**Бөтен кушымталар: CLI һәм серверлар.** `app record` CLI'ны (чыгу коды, stdout, stderr, язылган файллар) яки `--http` белән серверның һәр сорауга биргән җавапларын яза. `app front-door` `rust/app` ясый: керү ноктасын үз өстенә алган һәм әле портланмаган бар нәрсәне оригиналга тапшыручы Rust бинар файлы. `app wire` берәмлекләрне берәм-берәм күчерә, fallback өлеше нульгә төшкәнче `app replay` 100%та торырга тиеш, ә `app lift` саф Rust кушымтасын калдыра.

**Ян тәэсирләр дә исәпкә керә.** Webhook'ны яки хатны җибәрергә онытучы порт уңышсыз булырга тиеш. `app record --effects http,smtp` (яки `--effect-env WEBHOOK_URL=http-url`) кушымтаны һәр чыгучы чакыруны һәм хатны язучы җирле алмаштыручыларга юнәлтә, ә `--db-dump "sqlite3 app.db .dump"` һәр сораудан соң мәгълүмат базасын яза; replay портның да шулай эшләвен тикшерә.

**Оригинал үзгәрүен дәвам итәме?** `app drift` оригиналны аның язмасына каршы кабат эшләтә һәм хәзер башкача җавап бирүләрне санап чыга, ә [GitHub Action](install.md#in-ci) һәр push саен `gate` эшләтә.

**Карарны сез кабул итәсез.** Портның тотышын төзәткәндә, `rules --add "<rule>"` аны саклый, һәм киләсе һәр агент промпты аны үз эченә ала. rust-anything язган бар нәрсә `<repo>/rust/` эчендә.

**Хисап яки күчерү, үзегез сайлыйсыз.** `analyze` һәм `profile` хисап кына бирә: нәрсәне портларга кирәклекнең тәртипкә салынган планы һәм чын йөкләнештә нәрсә иң күп вакыт алуы. Болар гади боерыклар, шуңа күрә хисап бер токен да тотмый. `go` бер берәмлекне күчерә: иң кайнар функциягә күпер кора, аны яза, портны агентыгызга тапшыра, аннары җыя, чагыштыра һәм `gate` аша үткәрә, барысы да туры килгәндә генә кабыза (TS/JS, Python һәм PowerShell; `disable` кире сүндерә).

**Бер эшләтү күпме вакыт ала.** Бер `go` эшләтүе бер берәмлекне портлый, иң күбе `--rounds` агент әйләнеше белән (килешү буенча 3): берсе порт өчен, аннары һәр уңышсыз diff яки gate өчен берәр. Бөтен кушымта һәр берәмлеккә бер эшләтүдән тора, шуңа күрә теләсә кайсысыннан соң туктый аласыз.

**План өчен арзан модель, порт өчен көчле модель.** Планга модель кирәкми. Порт өчен теләсә нинди агент боерыгын бирегез: `rust-anything go --agent "claude --model <model>" -- <workload>`.

**Агентлар.** `rust-anything setup` аны Claude Code, Codex, Cursor, Gemini CLI һәм OpenCode'ка өсти. Теләсә кайсы башка MCP клиенты `rust-anything mcp` эшләтә ала, ә skill `npx skills add erkamyaman/rust-anything` ярдәмендә аерым да урнаштырыла ([урнаштыру](install.md) бүлеген карагыз).

## Боерыклар

| Боерык | Нәрсә эшли |
| --- | --- |
| `rust-anything go -- <workload>` | Профильли, иң кайнар функциягә күпер кора, аны яза, портны агентыгызга тапшыра, gate аша үткәрә, кабыза |
| `rust-anything analyze <repo>` | Тәртипкә салынган күчерү планы: берәмлекләр, әзерлек, куркынычлар, бәйлелекләр |
| `rust-anything profile <repo> -- <workload>` | Чын йөкләнештә нәрсә иң кайнар, нәрсәне портларга яки төркемләргә кирәк |
| `rust-anything bridge <repo> <unit>` | Бер берәмлек өчен бәйләнешләре булган Rust crate, stub'лар `src/port.rs` эчендә |
| `rust-anything record <crate>` | Оригинал нәрсә кайтарганын, нәрсә ыргытканын һәм нәрсә чыгарганын яза (`--inputs`, `--from-tests`, `--pin-clock`) |
| `rust-anything diff <crate>` | Язылган һәр очракны Rust модуленә каршы кабат эшләтә |
| `rust-anything bench <crate>` | Язылган очракларда оригинал һәм Rust вакытын үлчи, күперне кертеп |
| `rust-anything fuzz <crate>` | Ике якка да яңа кертү мәгълүматлары: язма колачламаган нәрсәләр |
| `rust-anything gate <crate>` | Әзерлекнең билгеләмәсе |
| `rust-anything enable` / `disable <crate>` | Чакыручыларны Rust'ка күчерә яки кире кайтара |
| `rust-anything report <crate>` | `REPORT.md` һәм pull request өчен карта |
| `rust-anything app record` / `front-door` / `wire` / `replay` / `lift` / `drift` | Бөтен CLI'ны яки серверны портлый |
| `rust-anything rules <repo> --add "<rule>"` | Сез төзәткән тотыш, киләсе һәр порт саклый |
| `rust-anything map <repo>` | Һәр берәмлек, аның crate'ы, очраклары һәм соңгы diff |
| `rust-anything log <repo>` | Һәр кабызу яки сүндерү, һәр wire, lift һәм gate нәтиҗәсе, `rust/audit.jsonl` эченнән |
| `rust-anything setup` / `doctor` / `mcp` | Агентлар өчен урнаштыру, эшләү мохитләрен тикшерү, MCP сервер |
