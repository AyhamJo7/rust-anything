## تېز باشلاش

بۇنى كود يازىدىغان ۋاكالەتچىڭىزگە چاپلاڭ:

```text
Install Rust Anything with npm i -g rust-anything, then run rust-anything setup. Run rust-anything go -- <slow command of this app> and finish the port until rust-anything gate passes.
```

ياكى ئۆزىڭىز ئورنىتىڭ:

```sh
cargo install rust-anything   # ياكى: npm install -g rust-anything
rust-anything setup           # ئۇنى Claude Code، Codex، Cursor، Gemini CLI ۋە OpenCode غا قوشىدۇ
rust-anything doctor          # ئەسلىي پروگراممىڭىزغا كېرەكلىك ئىجرا مۇھىتلىرىنى تەكشۈرىدۇ، ھەر بىرى ئۈچۈن تۈزىتىش ئۇسۇلىنىمۇ كۆرسىتىدۇ
```

> [!WARNING]
> خاتىرىلەش ئەسلىي پروگراممىنىڭ ھەقىقىي كودىنى ئىجرا قىلىدۇ. بىر نۇسخىسى ئۈستىدە ئىشلەڭ، ھەمدە مۇلازىمېتىرنى سىناق ساندانىغا قارىتىڭ.
> `record --sandbox` ۋە `app record --sandbox` ئۇنى تورسىز، ئامبارنى پەقەت ئوقۇشقىلا بولىدىغان ھالەتتە ۋە CPU بىلەن ئىچكى ساقلىغۇچ چەكلىمىسى بىلەن ئىجرا قىلىدۇ (Linux تا bubblewrap، macOS تا sandbox-exec؛ `doctor` ئۇنىڭ بار-يوقلۇقىنى تەكشۈرىدۇ).

> **ۋاكالەتچىلەرگە:** ئورنىتىش قەدەملىرى، بارلىق بۇيرۇقلار ۋە كۆچۈرۈش جەريانى ئۈچۈن [rustanything.ai/llms.txt](https://rustanything.ai/llms.txt) نى ئوقۇڭ.

## قانداق ئىشلەيدۇ

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/how-it-works/ug-dark.svg">
    <img src="assets/how-it-works/ug-light.svg" width="880" alt="analyze نېمىنى كۆچۈرۈشنى پىلانلايدۇ؛ rust-anything go كۆۋرۈك قۇرىدۇ، خاتىرىلەيدۇ، كۆچۈرۈشنى ۋاكالەتچىڭىزگە تاپشۇرىدۇ ۋە gate دىن ئۆتكۈزىدۇ، خاتىرىلەنگەن ھەر بىر ئەھۋال ماس كەلگۈچە تەكرارلايدۇ؛ ئاندىن enable چاقىرىقلارنى Rust قا ئالماشتۇرىدۇ">
  </picture>
</p>

**نېمە تامام دەپ ھېسابلىنىدۇ.** سىزنىڭ سىناقلىرىڭىز ئەمەس، ھەرىكەت. `record` ئەسلىي پروگراممىنى ھاسىل قىلىنغان ۋە بېرىلگەن كىرگۈزمىلەر بىلەن ئىجرا قىلىپ، ھەر بىر چاقىرىقنىڭ قايتۇرغىنى، تاشلىغىنى ۋە بېسىپ چىقارغىنىنى ساقلايدۇ. `gate` ئۆتسە كۆچۈرۈش تامام بولىدۇ: خاتىرىلەنگەن ھەر بىر ئەھۋال ماس كېلىدۇ، ھەمدە fmt، clippy، `cargo test`، `unsafe` تەكشۈرۈشى، stub تەكشۈرۈشى ۋە كۆچۈرمىگە چاپلانغان خاتىرىلەنگەن جاۋابلارنى تەكشۈرۈش ھەممىسى ئۆتىدۇ. ئۆزىڭىزنىڭ سىناقلىرىمۇ ئىجرا قىلىنىدۇ.

**سىناقلىرىڭىز ئەھۋالغا ئايلىنىدۇ.** `record --from-tests -- npx jest` (ياكى `pytest`) ئەسلىي پروگراممىنىڭ ئۆز سىناق توپلىمىنى ئىجرا قىلىدۇ ۋە ئۇنىڭ بىرلىككە قىلغان ھەر بىر چاقىرىقىنى خاتىرىلەيدۇ. `--pin-clock` ئىككى تەرەپتە سائەت ۋە تاسادىپىي سانلارنى مۇقىملاشتۇرىدۇ، شۇڭا چېسلاغا باغلىق كودمۇ ماس كېلەلەيدۇ.

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/how-it-works-app-dark.svg">
    <img src="assets/how-it-works-app-light.svg" width="880" alt="پۈتۈن ئەپنى كۆچۈرۈش: analyze پىلانلايدۇ، قارارنى سىز چىقىرىسىز، app record ئۇنىڭ ھەقىقىي ھەرىكىتىنى خاتىرىلەيدۇ، front door ئەسلىي پروگراممىنىڭ ئالدىدا Rust نى ئىجرا قىلىدۇ، بىرلىكلەر ھېچنېمە ئەسلىي پروگراممىغا قايتمىغۇچە بىر-بىرلەپ يۆتكىلىدۇ، ئاندىن lift ساپ Rust ئەپىنى قالدۇرىدۇ">
  </picture>
</p>

**پۈتۈن ئەپلەر: CLI ۋە مۇلازىمېتىرلار.** `app record` بىر CLI نى (چىقىش كودى، stdout، stderr، يېزىلغان ھۆججەتلەر) ياكى `--http` بىلەن بىر مۇلازىمېتىرنىڭ ھەر بىر تەلەپكە بەرگەن جاۋابلىرىنى خاتىرىلەيدۇ. `app front-door` `rust/app` نى قۇرىدۇ: كىرىش نۇقتىسىنى ئۆز ئۈستىگە ئالىدىغان ۋە تېخى كۆچۈرۈلمىگەن ھەممە نەرسىنى ئەسلىي پروگراممىغا ئۆتكۈزۈپ بېرىدىغان Rust ئىككىلىك ھۆججىتى. `app wire` بىرلىكلەرنى بىر-بىرلەپ يۆتكەيدۇ، fallback نىسبىتى نۆلگە چۈشكۈچە `app replay` 100% دە تۇرۇشى كېرەك، `app lift` بولسا ساپ Rust ئەپىنى قالدۇرىدۇ.

**قوشۇمچە تەسىرلەرمۇ ھېسابلىنىدۇ.** webhook ياكى ئېلخەتنى ئەۋەتىشنى ئۇنتۇغان كۆچۈرمە مەغلۇپ بولۇشى كېرەك. `app record --effects http,smtp` (ياكى `--effect-env WEBHOOK_URL=http-url`) ئەپنى سىرتقا چىققان ھەر بىر چاقىرىق ۋە خەتنى خاتىرىلەيدىغان يەرلىك ئورۇنباسارلارغا قارىتىدۇ، `--db-dump "sqlite3 app.db .dump"` بولسا ھەر بىر تەلەپتىن كېيىن سانداننى خاتىرىلەيدۇ؛ replay كۆچۈرمىنىڭمۇ ئوخشاش ئىش قىلىدىغانلىقىنى تەكشۈرىدۇ.

**ئەسلىي پروگرامما ئۆزگىرىۋاتامدۇ؟** `app drift` ئەسلىي پروگراممىنى ئۇنىڭ خاتىرىسىگە سېلىشتۇرۇپ قايتا ئىجرا قىلىدۇ ۋە ھازىر باشقىچە جاۋاب بېرىدىغانلارنى تىزىپ چىقىدۇ، [GitHub Action](install.md#in-ci) بولسا ھەر بىر push دا `gate` نى ئىجرا قىلىدۇ.

**قارارنى سىز چىقىرىسىز.** كۆچۈرمىنىڭ ھەرىكىتىنى تۈزەتكىنىڭىزدە، `rules --add "<rule>"` ئۇنى ساقلايدۇ، كېيىنكى ھەر بىر ۋاكالەتچى prompt ى ئۇنى ئۆز ئىچىگە ئالىدۇ. rust-anything يازىدىغان ھەممە نەرسە `<repo>/rust/` ئىچىدە تۇرىدۇ.

**دوكلاتمۇ ياكى كۆچۈرۈشمۇ، ئۆزىڭىز تاللاڭ.** `analyze` ۋە `profile` پەقەت دوكلات بېرىدۇ: نېمىنى كۆچۈرۈش كېرەكلىكى ھەققىدە تەرتىپلەنگەن پىلان، ۋە ھەقىقىي يۈك ئاستىدا قايسى قىسىمنىڭ ئەڭ كۆپ ۋاقىت ئالىدىغانلىقى. بۇلار ئاددىي بۇيرۇقلار، شۇڭا دوكلات ھېچقانداق token خەجلىمەيدۇ. `go` بىر بىرلىكنى كۆچۈرىدۇ: ئەڭ كۆپ ۋاقىت ئالىدىغان فۇنكسىيە ئۈچۈن كۆۋرۈك قۇرىدۇ، ئۇنى خاتىرىلەيدۇ، كۆچۈرۈشنى ۋاكالەتچىڭىزگە تاپشۇرىدۇ، ئاندىن قۇرۇپ چىقىدۇ، سېلىشتۇرىدۇ ۋە `gate` دىن ئۆتكۈزىدۇ، ھەممە نەرسە ماس كەلگەندىلا ئۇنى قوزغىتىدۇ (TS/JS، Python ۋە PowerShell؛ `disable` ئۇنى قايتا تاقايدۇ).

**بىر قېتىملىق ئىجرا قانچىلىك ۋاقىت ئالىدۇ.** بىر قېتىملىق `go` ئىجراسى بىر بىرلىكنى كۆچۈرىدۇ، ۋاكالەتچى ئەڭ كۆپ بولغاندا `--rounds` نۆۋەت ئىشلەيدۇ (كۆڭۈلدىكىسى 3): بىرى كۆچۈرۈش ئۈچۈن، ئاندىن مەغلۇپ بولغان ھەر بىر diff ياكى gate ئۈچۈن بىردىن. پۈتۈن ئەپ ھەر بىر بىرلىك ئۈچۈن بىر قېتىملىق ئىجرادىن تەركىب تاپىدۇ، شۇڭا خالىغان بىرىدىن كېيىن توختىسىڭىز بولىدۇ.

**پىلان ئۈچۈن ئەرزان مودېل، كۆچۈرۈش ئۈچۈن كۈچلۈك مودېل.** پىلانغا مودېل كېرەك ئەمەس. كۆچۈرۈش ئۈچۈن خالىغان ۋاكالەتچى بۇيرۇقىنى بېرىڭ: `rust-anything go --agent "claude --model <model>" -- <workload>`.

**ۋاكالەتچىلەر.** `rust-anything setup` ئۇنى Claude Code، Codex، Cursor، Gemini CLI ۋە OpenCode غا قوشىدۇ. باشقا ھەر قانداق MCP خېرىدارى `rust-anything mcp` نى ئىجرا قىلالايدۇ، skill نى يەنە `npx skills add erkamyaman/rust-anything` ئارقىلىق ئايرىم ئورناتقىلى بولىدۇ ([ئورنىتىش](install.md) غا قاراڭ).

## بۇيرۇقلار

| بۇيرۇق | نېمە قىلىدۇ |
| --- | --- |
| `rust-anything go -- <workload>` | ئانالىز قىلىدۇ، ئەڭ كۆپ ۋاقىت ئالىدىغان فۇنكسىيە ئۈچۈن كۆۋرۈك قۇرىدۇ، ئۇنى خاتىرىلەيدۇ، كۆچۈرۈشنى ۋاكالەتچىڭىزگە تاپشۇرىدۇ، gate دىن ئۆتكۈزىدۇ، قوزغىتىدۇ |
| `rust-anything analyze <repo>` | تەرتىپلەنگەن كۆچۈرۈش پىلانى: بىرلىكلەر، تەييارلىق، خەتەرلەر، بېقىنىشلار |
| `rust-anything profile <repo> -- <workload>` | ھەقىقىي يۈك ئاستىدا قايسى قىسىم ئەڭ كۆپ ۋاقىت ئالىدۇ، نېمىنى كۆچۈرۈش ياكى توپلاش كېرەك |
| `rust-anything bridge <repo> <unit>` | بىر بىرلىك ئۈچۈن باغلىنىشى بار Rust crate، stub لار `src/port.rs` دا |
| `rust-anything record <crate>` | ئەسلىي پروگراممىنىڭ قايتۇرغىنى، تاشلىغىنى ۋە بېسىپ چىقارغىنىنى خاتىرىلەيدۇ (`--inputs`، `--from-tests`، `--pin-clock`) |
| `rust-anything diff <crate>` | خاتىرىلەنگەن ھەر بىر ئەھۋالنى Rust مودۇلىغا سېلىشتۇرۇپ قايتا ئىجرا قىلىدۇ |
| `rust-anything bench <crate>` | خاتىرىلەنگەن ئەھۋاللاردا ئەسلىي پروگرامما بىلەن Rust نىڭ ۋاقتىنى ئۆلچەيدۇ، كۆۋرۈكنىمۇ قوشۇپ |
| `rust-anything fuzz <crate>` | ئىككى تەرەپكە يېڭى كىرگۈزمىلەر: خاتىرە قاپلىمىغان نەرسىلەر |
