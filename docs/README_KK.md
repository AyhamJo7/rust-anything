## Жылдам бастау

Мұны код жазатын агентіңізге қойыңыз:

```text
Install Rust Anything with npm i -g rust-anything, then run rust-anything setup. Run rust-anything go -- <slow command of this app> and finish the port until rust-anything gate passes.
```

Немесе өзіңіз орнатыңыз:

```sh
cargo install rust-anything   # немесе: npm install -g rust-anything
rust-anything setup           # оны Claude Code, Codex, Cursor, Gemini CLI және OpenCode-қа қосады
rust-anything doctor          # түпнұсқаңызға керек орындау орталарын тексереді, әрқайсысына түзету жолын береді
```

> [!WARNING]
> Жазу түпнұсқаның нақты кодын іске қосады. Көшірмемен жұмыс істеңіз және серверді тест дерекқорына бағыттаңыз.
> `record --sandbox` және `app record --sandbox` оны желісіз, репозиторийді тек оқуға арналған күйде және CPU мен жад шектеулерімен іске қосады (Linux-та bubblewrap, macOS-та sandbox-exec; `doctor` оның бар-жоғын тексереді).

> [!TIP]
> **Агенттерге:** орнату қадамдары, барлық командалар және порттау тәртібі үшін [rustanything.ai/llms.txt](https://rustanything.ai/llms.txt) оқыңыз.

## Бұл қалай жұмыс істейді

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/how-it-works/kk-dark.svg">
    <img src="assets/how-it-works/kk-light.svg" width="880" alt="analyze нені порттауды жоспарлайды; rust-anything go көпір жасайды, жазады, портты агентіңізге береді және gate арқылы өткізеді, жазылған әр жағдай сәйкес келгенше қайталайды; содан кейін enable шақыруларды Rust-қа ауыстырады">
  </picture>
</p>

**Не дайын деп саналады.** Сіздің тесттеріңіз емес, мінез-құлық. `record` түпнұсқаны генерацияланған және берілген кіріс деректерімен іске қосып, әр шақырудың нені қайтаратынын, лақтыратынын және шығаратынын сақтайды. Порт `gate` өткенде дайын: жазылған әр жағдай сәйкес келеді, сондай-ақ fmt, clippy, `cargo test`, `unsafe` тексерісі, stub тексерісі және портқа қойылған жазылған жауаптарды тексеру де өтеді. Өз тесттеріңіз де іске қосылады.

**Тесттеріңіз жағдайларға айналады.** `record --from-tests -- npx jest` (немесе `pytest`) түпнұсқаның өз тест жиынын іске қосып, оның бірлікке жасайтын әр шақыруын жазады. `--pin-clock` екі жақта да сағат пен кездейсоқ сандарды бекітеді, сондықтан күнге тәуелді код та сәйкес келе алады.

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/how-it-works-app-dark.svg">
    <img src="assets/how-it-works-app-light.svg" width="880" alt="Тұтас қолданбаны порттау: analyze оны жоспарлайды, шешімдерді сіз қабылдайсыз, app record оның нақты мінез-құлқын жазады, front door түпнұсқаның алдында Rust-ты іске қосады, бірліктер ештеңе түпнұсқаға қайтпайынша бір-бірлеп көшеді, содан кейін lift таза Rust қолданбасын қалдырады">
  </picture>
</p>

**Тұтас қолданбалар: CLI және серверлер.** `app record` CLI-ды (шығу коды, stdout, stderr, жазылған файлдар) немесе `--http` арқылы сервердің әр сұрауға берген жауаптарын жазады. `app front-door` `rust/app` жасайды: кіру нүктесін өзіне алатын және әлі портталмаған бәрін түпнұсқаға беретін Rust бинарлық файлы. `app wire` бірліктерді бір-бірлеп көшіреді, fallback үлесі нөлге түскенше `app replay` 100%-да тұруы керек, ал `app lift` таза Rust қолданбасын қалдырады.

**Жанама әсерлер де есептеледі.** Webhook-ты немесе хатты жіберуді ұмытқан порт сәтсіз болуы керек. `app record --effects http,smtp` (немесе `--effect-env WEBHOOK_URL=http-url`) қолданбаны әр шығыс шақыруды және хатты жазатын жергілікті алмастырғыштарға бағыттайды, ал `--db-dump "sqlite3 app.db .dump"` әр сұраудан кейін дерекқорды жазады; replay порттың да солай істейтінін тексереді.

**Түпнұсқа өзгере бере ме?** `app drift` түпнұсқаны оның жазбасымен қайта ойнатып, енді басқаша жауап беретінін тізіп шығады, ал [GitHub Action](install.md#in-ci) әр push кезінде `gate` іске қосады.

**Шешімді сіз қабылдайсыз.** Порттың мінез-құлқын түзеткенде, `rules --add "<rule>"` оны сақтайды, және кейінгі әр агент промпты оны қамтиды. rust-anything жазатын бәрі `<repo>/rust/` ішінде.

**Есеп пе, көшіру ме, өзіңіз таңдайсыз.** `analyze` және `profile` тек есеп береді: нені порттау керектігінің реттелген жоспары және нақты жүктеме кезінде не ең көп уақыт алатыны. Бұлар қарапайым командалар, сондықтан есеп ешқандай токен жұмсамайды. `go` бір бірлікті көшіреді: ең қызу функцияға көпір жасайды, оны жазады, портты агентіңізге береді, содан кейін құрастырады, салыстырады және `gate` арқылы өткізеді, бәрі сәйкес келгенде ғана қосады (TS/JS, Python және PowerShell; `disable` қайта өшіреді).

**Бір іске қосу қанша уақыт алады.** Бір `go` іске қосуы бір бірлікті порттайды, ең көбі `--rounds` агент айналымымен (әдепкі бойынша 3): біреуі порт үшін, содан кейін әр сәтсіз diff немесе gate үшін біреуден. Бүкіл қолданба әр бірлікке бір іске қосудан тұрады, сондықтан кез келгенінен кейін тоқтай аласыз.

**Жоспарға арзан модель, портқа күшті модель.** Жоспарға модель керек емес. Порт үшін кез келген агент командасын беріңіз: `rust-anything go --agent "claude --model <model>" -- <workload>`.

**Агенттер.** `rust-anything setup` оны Claude Code, Codex, Cursor, Gemini CLI және OpenCode-қа қосады. Кез келген басқа MCP клиенті `rust-anything mcp` іске қоса алады, ал skill `npx skills add erkamyaman/rust-anything` арқылы бөлек те орнатылады ([орнату](install.md) бөлімін қараңыз).

## Командалар

| Команда | Не істейді |
| --- | --- |
| `rust-anything go -- <workload>` | Профильдейді, ең қызу функцияға көпір жасайды, оны жазады, портты агентіңізге береді, gate арқылы өткізеді, қосады |
| `rust-anything analyze <repo>` | Реттелген көшіру жоспары: бірліктер, дайындық, тәуекелдер, тәуелділіктер |
| `rust-anything profile <repo> -- <workload>` | Нақты жүктеме кезінде не ең қызу екені, нені порттау немесе топтау керек |
| `rust-anything bridge <repo> <unit>` | Бір бірлікке арналған байланыстары бар Rust crate, stub-тар `src/port.rs` ішінде |
| `rust-anything record <crate>` | Түпнұсқаның нені қайтаратынын, лақтыратынын және шығаратынын жазады (`--inputs`, `--from-tests`, `--pin-clock`) |
| `rust-anything diff <crate>` | Жазылған әр жағдайды Rust модулімен қайта ойнатады |
| `rust-anything bench <crate>` | Жазылған жағдайларда түпнұсқа мен Rust уақытын өлшейді, көпірді қоса |
| `rust-anything fuzz <crate>` | Екі жаққа да жаңа кіріс деректері: жазба қамтымаған нәрселер |
| `rust-anything gate <crate>` | Дайындықтың анықтамасы |
| `rust-anything enable` / `disable <crate>` | Шақырушыларды Rust-қа ауыстырады немесе кері қайтарады |
| `rust-anything report <crate>` | `REPORT.md` және pull request үшін карта |
| `rust-anything app record` / `front-door` / `wire` / `replay` / `lift` / `drift` | Тұтас CLI-ды немесе серверді порттайды |
| `rust-anything rules <repo> --add "<rule>"` | Сіз түзеткен мінез-құлық, кейінгі әр порт сақтайды |
| `rust-anything map <repo>` | Әр бірлік, оның crate-і, жағдайлары және соңғы diff |
| `rust-anything log <repo>` | Әр қосу немесе өшіру, әр wire, lift және gate нәтижесі, `rust/audit.jsonl` ішінен |
| `rust-anything setup` / `doctor` / `mcp` | Агенттерге орнату, орындау орталарын тексеру, MCP сервері |
